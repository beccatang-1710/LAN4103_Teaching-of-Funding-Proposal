Step 1: Writing Organisation Information (Unit 2)

第一步：撰写机构资料（单元二）

For writing Organisation information, identify key components on the homepage and use the following grammatical structures:

撰写机构资料时，请从主页中识别关键信息，并运用以下语法结构：
  • Structure 1: [past participle, "-ed"] + in + Establishment/Founding/Formation year
  • 结构一：[过去分词] + in + 成立/创办年份
  • Structure 2: Organization name + is a + [business nature]
  • 结构二：机构名称 + is a + [业务性质]
  • Structure 3: specialising in / dedicated to / committed to / devoted to / focusing on + [action / area]
  • 结构三：specialising in / dedicated to / committed to / devoted to / focusing on + [行动/领域]
  • Structure 4: Additionally, / Also, + we organize / run / conduct / provide / offer + organization's mission / services / work
  • 结构四：Additionally / Also + we organize / run / conduct / provide / offer + 机构使命/服务
  • Structure 5: [to + verb] + purpose of the mission / services / work
  • 结构五：[to + 动词] + 使命/服务的目的

Examples / 范例

Example 1 (InnoDesign): Formed in 2001, InnoDesign is a product design consultancy devoted to offering customised product prototyping services to local and international manufacturers.

范例一（InnoDesign）：InnoDesign 成立于2001年，是一间产品设计顾问公司，致力于为本地及国际制造商提供定制产品原型服务。

Also, we host community workshops to engage participants in hands-on product design activities.

此外，我们举办社区工作坊，让参与者亲身参与产品设计活动。

范例二（StyleScope）：StyleScope Hong Kong 成立于2020年，是一间时尚媒体公司，专注于为时尚爱好者出版时装及美容杂志。

Additionally, we run reader engagement campaigns to invite fashion ideas or styling tips from readers.

此外，我们举办读者互动活动，邀请读者分享时尚创意及穿搭贴士。

Example 3 (Island Esports): Established in 2013, Island Esports is a gaming association dedicated to nurturing esports talent in Hong Kong.

范例三（Island Esports）：Island Esports 成立于2013年，是一个致力于培养香港电竞人才的电竞协会。

Also, we offer a range of esport games and competitions to nurture positive gaming culture.

Step 2: Writing Project Details (Unit 3)

第二步：撰写项目详情（单元三）

For writing Project details (Implementation + Amount of funding requested), identify duration and action of each phase on Notes of meeting.

撰写项目详情（执行计划 + 申请资助金额）时，请从会议记录中识别各阶段的时间及行动。

a. Implementation Formula / 执行计划公式

  • The project will be completed in three stages/phases, each lasting XXX months/weeks.
  • 项目将分三个阶段进行，每阶段为期XXX个月/周。
  • In phase 1, we will [verb]..., in phase 2, we will [verb]...
  • 在第一阶段，我们将……；在第二阶段，我们将……
  • In phase 3, / In the final phase, ...
  • 在第三阶段 / 在最后阶段，……

b. Amount of Funding Requested Formula / 申请资助金额公式

  • It is estimated that a total of $xxxxx will be required for the project. For details of the breakdown, please refer to the attachment.
  • 项目预计所需资金总额为$xxxxx。详情请参阅附件。
  • (Alternative) The project is estimated to cost around $xxxxx. The details of the breakdown are attached for your information.
  • （替代写法）项目预计成本约为$xxxxx。费用明细已附上供参考。

Step 3: Writing Justification for Funding (Unit 4)

第三步：撰写资助理由（单元四）

For writing Justification, identify 3 benefits on your handwritten notes. Use the following vocabulary and grammatical structures:

撰写资助理由时，请从手写笔记中识别三项益处，并运用以下词汇和语法结构：
  • Benefit 1: The project will + provide / offer / feature / give + [Benefit 1]
  • 益处一：项目将 + 提供/展示/带来 + [益处一]
  • Elaboration: verb+ing (e.g. strengthening / encouraging) + [result / elaboration]
  • 阐述：动词+ing（如加强/促进）+ [结果/阐述]
  • Benefit 2: Additionally, / Moreover, / In addition, it / the project will + [Benefit 2]
  • 益处二：此外 / 而且 / 与此同时，该项目将 + [益处二]
  • Elaboration: which + [result / elaboration]
  • 阐述：which + [结果/阐述]
  • Alignment with Funder: Furthermore, / Also, this project's aim closely aligns with / is in line with the mission and values of [funder].
  • 与资助方的契合：再者，本项目的目标与[资助方]的使命及价值观高度契合。

Step 4: Writing Supplementary Information (Unit 5)

第四步：撰写补充资料（单元五）

For writing Supplementary information, identify the possible concern and solution and a concluding remark on your handwritten notes.

撰写补充资料时，请从手写笔记中识别可能的关注事项、解决方案及结语。
  • 1. Acknowledging Concern: We are aware that / We acknowledge / We understand that there might be concerns about ... [concern]
  • 1. 承认关注事项：我们明白 / 我们理解可能会有……的顾虑
  • 2. Proposing Solution: However, we will ensure that... / However, please rest assured that we will... [solution]
  • 2. 提出解决方案：然而，我们将确保…… / 请放心，我们将……
  • 3. Concluding Remark: We are confident that the project / [verb-ing phrase], which [project aim], will [summary of benefits / positive outcome].
  • 3. 结语：我们坚信，该项目 / [动词+ing短语]，[项目目标]，将[益处/正面成果的总结]。

范例一 — 电竞比赛（服务器延迟技术问题）：
我们明白可能会有技术问题的顾虑，例如比赛期间的服务器延迟。请放心，我们将确保使用高性能服务器，并在活动前进行压力测试，以保证所有参与者享有流畅的体验。

我们坚信，举办是次电竞比赛，展示本地电竞选手的出色表现，将促进公众对竞技游戏的正面看法，赢得社会更多支持。

范例二 — 电动车充电站网络（设备安全）：
